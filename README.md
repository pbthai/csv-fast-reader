A single-pass reader for broken CSV files. It gives the same columns, rows and errors as csv-reader 1.0.0, and it takes fast paths through records that hold no quotes or stray carriage returns.

## Run it

```sh
node main.ts
```

It reads `/input/cases.json` and writes `/output/answers.json` (`MAKEFUN_INPUT_DIR` and `MAKEFUN_OUTPUT_DIR` override the two folders).
